  #### Phần 1: Chạy hạ tầng & Backend ở Local

  Mở cửa sổ Terminal 1 (cmd hoặc PowerShell):

    # Di chuyển vào thư mục dự án v2
    cd D:\User\ProjectGithub\vinaiaction\C2-App-012\he_thong_kho_luu_tru_tri_thuc
    
    # 1. Khởi động Docker (MySQL, Redis, MinIO, Qdrant)
    docker compose -f docker-compose.v2.yml up -d
    
    # 2. Chạy Backend local (sẽ chạy trên cổng 8081)
    ..\venv\Scripts\activate
    powershell -ExecutionPolicy Bypass -File run_v2_demo.ps1
    
  #### Phần 2: Mở đường hầm API (Bắt buộc để Vercel kết nối)

  Mở một cửa sổ Terminal 2 mới và giữ nguyên (không tắt):

    ssh -o StrictHostKeyChecking=no -R eduvault-api-c2-012-v3:80:127.0.0.1:8081 serveo.net

   -> Link API cố định công khai của bạn sẽ là: `https://eduvault-api-c2-012-v3.serveousercontent.com`

3. TRIỂN KHAI FRONTEND LÊN VERCEL
Chạy các lệnh sau tại thư mục frontend:
   cd D:\User\ProjectGithub\vinaiaction\C2-App-012\he_thong_kho_luu_tru_tri_thuc\frontend

   # Bước 1: Tắt các tiến trình Node cũ nếu có để giải phóng cổng/bộ nhớ
   taskkill /F /IM node.exe

   # Bước 2: Cài đặt thư viện frontend
   npm install

   # Bước 3: Đăng nhập & Liên kết dự án với Vercel (nếu chưa làm)
   npx vercel login
   npx vercel link

   # Bước 4: Thiết lập biến môi trường API URL trên Vercel trỏ tới Serveo Tunnel
   npx vercel env add NEXT_PUBLIC_API_URL production --value https://eduvault-api-c2-012-v3.serveousercontent.com --yes --force

    # 4. Build và deploy thực tế lên Vercel Production
    npx vercel --prod --force
