# Dữ liệu sinh ra khi chạy

Thư mục `var/` chứa artifact runtime:

- `reports/`: output benchmark và báo cáo sinh tự động
- `logs/`: log backend/frontend cũ và log vận hành
- `tmp/`: file tạm
- `artifacts/`: build/dist artifact
- `sample-data/`: chỗ dành cho dữ liệu mẫu nếu cần

## Lưu ý

- Không đặt source code ở đây.
- Không dùng `var/` làm nơi chứa tài liệu thiết kế.
- Phần lớn nội dung trong `var/` nên được ignore khỏi git.
